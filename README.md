# amalgam

Amalgam is a proposed Lean 4 project studying what partial observations and
their admissible comparisons determine about possible global realizations.
Its first target is an exact criterion for when reducing local descriptions
preserves their joint compatibility.

[PROPOSAL.md](PROPOSAL.md) defines the mathematical scope, roadmap, and
completion criteria. The repository currently contains the proposal and Nix
development tooling; the Lean implementation has not started.
